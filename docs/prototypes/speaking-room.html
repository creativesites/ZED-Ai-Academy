Same teacher, three tiers

Text, Voice and Live change the brain and the voice behind the teacher. The character, gestures and scene stay the same, so moving up a tier never feels like a different product.

Actions are AI events

The model sends small events like gesture("wave") and show_card(…). The avatar plays them. Listening behaviour (blinks, nods, eye contact) runs on the device with no AI cost.

This is a sketch, not the final art

The character is drawn in code to show motion and timing. In production an illustrator builds her in Rive with real rigging, so the same file runs on the web and in the mobile app.
