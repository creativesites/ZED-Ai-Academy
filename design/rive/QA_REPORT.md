# ZAI Teacher Rive files: QA report (v0.1, 3D-look pass)

Built with the Rive CLI 1.5.1 from RML generated by `design/rive/tools/*.mjs`.
Rebuild: `node tools/gen_teacher.mjs && rive teacher --once` (and `gen_scenes.mjs`, `rive scenes --once`).
Contract: `docs/rive/teacher.contract.json` (v1.0.0, not changed).

## Look and feel
The brief asked for flat colour. This pass follows the request for a **3D look**. Every form is lit with
alpha-only gradient overlays on top of a bound base colour (volume shading, warm bounce light, amber rim light,
glossy hair bands, spherical eyes with catchlights, tube lips, shaded hands, contact shadows). Recolouring through
the bound colours keeps the lighting. No Feather is used, so it renders on the canvas renderer (checked in Chrome).

## Tone tracing
Not a Follow Path constraint. The fingertip is a 2-bone IK solve baked to keyframes along the contract polyline at constant
speed (same durations, exact `traceBox` coordinates). Verified by overlaying the path on renders (within ~15 px).
The far top-right of `traceBox` is at the arm's reach limit, the body lifts 22 px to make it.

## IMPORTANT runtime note
@rive-app/canvas **2.31.2 fires a view-model trigger only once** (a second `playGesture` does nothing).
2.47.1 works repeatedly. Use >= 2.47 on web (and check the React Native runtime version). State machine input mirrors for
React Native were **not** added.

## Characters
Lín Lǎoshī (Chinese). Sofía, Camille, Nurse Tendai are **Black/African** (deep skin tones, natural hair: curls, puff bun, close crop;
presets in `presets.json`). Face structure (nose, lips, eye shape) is shared across all four, only colour, hair, outfit and
props change. Features beyond that are a next step.

## Known gaps vs the brief
- No style-frame/character-sheet checkpoints done; previews are PNG contact sheets in `previews/`, no MP4/GIF (CLI has no video export).
- No `.rev` source (needs `rive login`); the generator scripts are the editable source.
- `count` pulses the hand n times, it does not show n fingers. Hand poses: open, point, thumb, fist only.
- No hair/earring secondary motion; mood mouth-corner lift is subtle (mouth scale/tilt only).
- Teacher idle ignores reducedMotion (idle is already small); Bust idle stops.
- Props: held in the screen-left hand, they travel with it during gestures. Tea steam loops.
- Scenes are first-pass flat layered vector, less 3D than the characters; sparkle/swallow/lantern loops built but not reviewed.
- fps: not measured on a phone. Headless Chrome (no GPU): 120 frames advance+draw in ~180 ms. Please test on a real Android device.
