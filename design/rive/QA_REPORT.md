# ZAI Teacher Rive files: QA report (v0.2)

Built with Rive CLI 1.5.1 from RML generated by `tools/*.mjs` (see `README.md`). Contract: `docs/rive/teacher.contract.json` **1.1.0**.

## What changed since v0.1
- **`faceStyle` enum (contract 1.1.0, `FaceStyle`: `lin`, `sofia`, `camille`, `tendai`, `tinashe`, default `lin`).** Each value swaps face shape,
  nose, lips (all 9 visemes per style), eye form, lashes and brows. `tinashe` also adds a short beard and hides earrings.
  `tinashe` is a fifth value beyond the four requested, for the male tutor Tinashe. `TeacherBust` supports `faceStyle` too.
  Sofía, Camille, Nurse Tendai and Tinashe are Black/African, Lín Lǎoshī is unchanged. Close-up: `previews/faces_closeup.png`.
- **`count` shows exactly `countTo` fingers (1-5)**: fingers appear one by one (index, middle, ring, pinky, then thumb at 5), 0.5 s each,
  with one `gesturePeak` per finger. Pictures: `previews/count_hands.png`.
- Triggers fired during a gesture's 150 ms blend-in were dropped; fixed with `enableEarlyExit` on the gesture transitions.
- Counting hand uses an upright wrist (`pointAngle`), cheeks use a warmer blush that reads on dark skin.

the file this is fixed for the frame-stepped test (nod fired 3 frames into a wave starts immediately).

## Performance check (teacher + scene together, canvas renderer)
`qa/perf.html`: `Scene_TeaHouse` (1200x750) with `Teacher` (600x750) over it, both running their state machines with `@rive-app/canvas` 2.47.1,
`speaking` on, a new random viseme at ~30 Hz, a new gesture every 1.8 s. Driven over CDP by `qa/perf_cdp.mjs`, 12-15 s per run.

| CPU throttle | Runs | Average fps | Median frame | p95 frame |
|---|---|---|---|---|
| 1x | 3 | 55-59 (one run had a single 3.8 s stall, 34.5 average) | 16.7 ms | 16.8 ms |
| **4x** | 9 on this version (43.2 to 48.5) | **43-48** | 16.7 ms | 33-50 ms |

An earlier session measured 49-55 fps at 4x on the previous file; an A/B of the previous commit's file against this one under the same
conditions gave 43.6-44.0 vs 45.6-47.5, so the face-style work did not slow it down; the difference is host noise. **The 60 fps target is not
met at 4x throttle** (a typical frame is 16.7 ms but 23-60 frames per 12 s run take 33 ms or more). This is a headless Chrome run on an M1 Mac,
a proxy only. Test a real 2019-era Android phone. Likely wins if needed: fewer gradient layers on the hair, smaller scene canvas, lower
device pixel ratio.

## Known gaps
- Hand pose count for `count` is right, but the thumb at 5 is thin. Tone-trace uses baked IK, not a Follow Path constraint (same path, durations).
- Tinashe wears a blazer; plain white shirt is faked by setting `accentColor` equal to `outfitSecondary` (the stripes then show only as faint
  shading). A real `shirt` outfit style would need a contract bump.
- Mood mouth-corner lift is subtle; no hair/earring secondary motion; scenes are flatter than the characters; no MP4/GIF previews.
- Parallax scene depth and React Native fallback inputs: separate PRs.
